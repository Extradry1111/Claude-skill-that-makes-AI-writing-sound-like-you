# Template launch

## Program rules (non-negotiable)

- The template must be shared in a **public X post that includes its share link**.
- Posts promoting your templates must use **X's paid partnership label**.
- Ask for the share link if it's missing. Never invent one.

## Inputs to collect

1. Template name and share link
2. The one job it does, in a sentence
3. A real example output, such as a screenshot or pasted text. **Ask for it, because proof beats claims.**
4. Who it's for

## Output

**Main post, with 2 hook options:**
```
[hook: the job it does, or the time it saves. Under 110 chars, no hype words]

[what it does in 1 line]

what you get:
→ [routine / output 1]
→ [routine / output 2]
→ [routine / output 3]

copy it free: [share link]
```
Add a reminder that says **Turn on "Paid partnership" before posting.**

**3 quote-posts** for the next 3 to 7 days, each with a new angle:
1. A real output from today ("this morning's brief: …")
2. One user question answered by the bot
3. A changelog ("v2: added X because people asked")

## Rules

- Don't invent user counts, testimonials or earnings.
- No em dashes. Use a period, a colon or →.
- Attach a screenshot or a short screen recording of the bot working. Posts with proof get bookmarked.
